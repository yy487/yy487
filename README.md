## Main Project

### [vn-tool](https://github.com/yy487/vn-tool)

`vn-tool` 是我整理和开发的视觉小说 / Galgame 补丁制作工具仓库，主要包含：

- 文本提取 / 注入工具
- 封包 / 解包辅助工具
- 字体处理工具
- 编码转换与字符映射工具
- 补丁制作流程辅助脚本
- 引擎格式分析与实验工具
